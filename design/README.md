# design — .pen 파일 규칙

Figma 디자인을 Pencil(.pen)로 옮긴 원본을 둔다. Pencil MCP로 읽고 코드로 변환한다.

## 파일 (필수)

| 파일         | 화면                                                    |
| ------------ | ------------------------------------------------------- |
| `design.pen` | 공통·학생·선생님·관리자 화면 (구 `student-teacher.pen`) |

- `.pen`은 암호화 포맷이라 **git 머지가 불가능**하다. 파일이 하나이므로 두 명이 동시에 수정하지 않는다 — 수정 전 팀원과 조율하고, 수정한 사람이 커밋한다.
- 파일은 Pencil 데스크톱 앱에서 연다. 이 폴더에 두고 커밋한다.

## 작업 흐름

1. Pencil 데스크톱 앱 실행 (MCP 연결 필수)
2. Figma → `design.pen`으로 화면 옮기기
3. Pencil MCP로 `.pen` → 코드 생성, `src/app/<라우트>/page.tsx` 및 `src/features/<역할>/`에 반영
